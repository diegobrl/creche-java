#  Creche Software - Sistema de Gestão Educacional

Sistema Java para gerenciamento de turmas, crianças e professores em creches, desenvolvido com Programação Orientada a Objetos (POJ).

##  Tecnologias Utilizadas
- **Linguagem**: Java 11+
- **Bibliotecas**: `java.time` (para cálculo de idades), `java.util` (para coleções)
- **Paradigma**: POO (Herança, Polimorfismo, Encapsulamento)
- **Padrões**: MVC implícito
